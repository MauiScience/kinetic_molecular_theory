# kinetic_molecular_theory
3.5 Kinetic Molecular Theory & the Maxwell–Boltzmann Distribution
Covers AP Chemistry CED Topic 3.5. Students explore a real-time particulate model (elastic collisions, speed-coded particles) alongside a live Maxwell–Boltzmann speed distribution curve, compare gases by molar mass and temperature, and connect KE = ½mv² to the Kelvin/average-KE relationship. Includes a Guided Lab (temperature effects, molar-mass effects, and the pressure/volume misconception trap) and a three-tier quiz with per-question feedback.
